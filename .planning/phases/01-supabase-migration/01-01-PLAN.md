<task type="auto">
  <name>Task 2: Rewrite DB connection to use postgres-js driver</name>
  <files>src/lib/db/index.ts</files>
  <action>
    Replace the contents of `src/lib/db/index.ts` with a new implementation using `drizzle-orm/postgres-js` and the `postgres` package.

    **Key changes from current implementation:**

    1. **Import change:** Replace `import { drizzle } from 'drizzle-orm/node-postgres'` and `import { Pool } from 'pg'` with `import { drizzle } from 'drizzle-orm/postgres-js'` and `import postgres from 'postgres'`

    2. **Connection strategy:** Use `postgres()` directly (not a Pool class) — the `postgres` package manages its own internal connection pool.

    3. **SSL handling:** Supabase (even self-hosted) typically requires SSL. Keep the SSL logic but simplify:
       - In production: always use SSL with `rejectUnauthorized: false` (Supabase uses self-signed certs on DO)
       - In development (localhost): no SSL

    4. **PgBouncer compatibility:** Supabase uses PgBouncer on port 6543. The `postgres` package supports this natively. Add a `prepare: false` option when PgBouncer transaction mode is detected (port 6543), since prepared statements don't work with PgBouncer in transaction mode.

    5. **Pool settings:** Configure for serverless-friendly defaults:
       - `max: 10` (matches current, but comment that PgBouncer handles pooling upstream)
       - `idle_timeout: 30` (30 seconds, for serverless warm connections)
       - `connect_timeout: 10` (10 seconds, generous for DO network)

    **Implementation template:**

    ```typescript
    import { drizzle } from 'drizzle-orm/postgres-js';
    import postgres from 'postgres';
    import * as schema from './schema';

    export type AppDb = ReturnType<typeof drizzle<typeof schema>>;

    let dbInstance: AppDb | null = null;
    let sqlInstance: ReturnType<typeof postgres> | null = null;

    export function getDb(): AppDb {
      if (dbInstance) return dbInstance;

      const connectionString = process.env.DATABASE_URL;
      if (!connectionString) {
        throw new Error(
          'DATABASE_URL environment variable is not set. ' +
          'Add it to .env.local for development or to your hosting platform environment variables.'
        );
      }

      const isLocalhost = connectionString.includes('localhost') || connectionString.includes('127.0.0.1');
      const isProduction = process.env.NODE_ENV === 'production';
      const isPgBouncer = connectionString.includes(':6543');

      console.log('🔌 Connecting to PostgreSQL via postgres-js...');

      sqlInstance = postgres(connectionString, {
        ssl: (isProduction && !isLocalhost) ? { rejectUnauthorized: false } : false,
        max: 10,
        idle_timeout: 30,
        connect_timeout: 10,
        // PgBouncer transaction mode: prepared statements must be disabled
        prepare: !isPgBouncer,
      });

      dbInstance = drizzle(sqlInstance, { schema });
      return dbInstance;
    }

    // For direct SQL queries when needed (e.g., for raw queries, health checks)
    export function getSql() {
      getDb(); // ensure connection is initialized
      return sqlInstance!;
    }
    ```

    **Do NOT change:**
    - The singleton pattern (lazy initialization, cached instance)
    - The `AppDb` type export
    - The `schema` import structure
    - The error message for missing DATABASE_URL

    import dotenv from 'dotenv';
    import path from 'path';

    const __filename = fileURLToPath(import.meta.url);
    const __dirname = path.dirname(__filename);
    dotenv.config({ path: path.resolve(__dirname, '../.env.local') });

    const connectionString = process.env.DATABASE_URL;
    
    async function main() {
      if (!connectionString) {
        console.error('DATABASE_URL is not set in .env.local');
        process.exit(1);
      }

      const sql = postgres(connectionString, { ssl: false, max: 1 });
      
      try {
        console.log('Attempting to connect to PostgreSQL...');
        const [row] = await sql`SELECT NOW()`;
        console.log('Successfully connected!');
        console.log('Query result (SELECT NOW()):', row);

        const tables = await sql`
          SELECT table_name FROM information_schema.tables 
          WHERE table_schema = 'public' ORDER BY table_name
        `;
        console.log('Tables in public schema:');
        if (tables.length === 0) {
          console.log('  (No tables found)');
        } else {
          tables.forEach(t => console.log(`  - ${t.table_name}`));
        }
      } catch (err) {
        console.error('Database connection failed:');
        console.error(err);
      } finally {
        await sql.end();
      }
    }
